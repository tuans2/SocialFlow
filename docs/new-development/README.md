# 📂 New Development — SocialFlow

> Thư mục này chứa các tài liệu và kế hoạch phát triển mới cho dự án SocialFlow.
> Nội dung gốc của repository được giữ nguyên, không bị thay đổi.

## Mục đích

Tách biệt rõ ràng giữa:
- **Codebase gốc** (`backend/`, `frontend/`, `configs/`) — giữ nguyên trạng thái ban đầu
- **Tài liệu phát triển mới** (`docs/new-development/`) — PRD, plans, specs, notes

## Danh sách tài liệu

| File | Mô tả | Ngày tạo |
|------|--------|----------|
| [PRD.md](./PRD.md) | Product Requirements Document — Tổng quan toàn bộ dự án từ codebase audit | 2026-09-02 |

## Quy tắc

1. **Không chỉnh sửa file gốc** trừ khi có kế hoạch cụ thể được phê duyệt.
2. Mọi ý tưởng, kế hoạch, specs mới đều đặt trong thư mục này.
3. Đặt tên file theo format: `kebab-case.md` (ví dụ: `improvement-plan.md`, `api-redesign.md`).
